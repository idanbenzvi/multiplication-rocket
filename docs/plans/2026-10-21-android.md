# The Android app (Capacitor)

## Goal

The game as an Android app for Google Play, on the `androidcapacitor` branch. The first step: show
that the game builds into an app that installs and plays. Then the Android details (below), then
the Play Store.

## How it's built

- **[Capacitor](https://capacitorjs.com) 8** (MIT): the web build (`dist/`) is bundled into the app
  and played in Android's WebView, so the app works offline.
  - App id `com.falcondeergames.multiplicationrocket`, after the studio's contact address (the
    user didn't want GitHub showing in the final version, and the app id is its address on Play).
    It can't change once the app is on Play.
  - The packages are dev dependencies, like the rest of the repo's, so the Electron app is
    unaffected.
- **`android/`** is the generated Gradle project, committed. The copied web build and Gradle's
  output are ignored.
- **Commands:**
  - `npm run android` builds the web version and copies it into the Android project
    (`cap sync android`).
  - `npm run android:apk` also builds a debug APK, in
    `android/app/build/outputs/apk/debug/app-debug.apk`.
- **The toolchain:** Java 21 and the Android SDK (platform 36, build-tools 35). Gradle 8.14 is
  fetched by the wrapper. Set `JAVA_HOME` and `ANDROID_HOME` before building.
- **Icons and splash:** `scripts/android-art.sh` makes them from the game's icon
  (`public/icons/icon-512.png`).
  - The adaptive icon's foreground is the whole icon at 76 of its 108 dp, so any launcher mask
    keeps the rocket.
  - The older icons (Android 7) are the icon itself, plus a round one.
  - The splash screens are the icon on the game's night purple (`#241b3f`). The theme puts the
    same colour behind the app and its system bars, with light icons on them.

## Checked on an emulator (Android 15, WebView 124)

- It installs and opens on the night purple, then plays the studio splash.
- The welcome screen, the hangar (all three ships with the pilot in the window) and the game
  itself (the 3D rocket, the plume, the aurora) all work.
- Answering by touch works: the "Yes!", the First Star badge, the fuel rising.
- The launcher shows the rocket icon.

## Done since

- **The Back button** (`src/native/back.ts`, `@capacitor/app`):
  - Each screen, sheet or dialog says, while it's open, what Back does (`useBack`): what its own
    close, cancel or quit button does. Back runs the one opened last.
  - The Academy turns back a page.
  - With nothing open (the game, a bonus round) Back sends the app to the background instead of
    quitting it.
- **Fullscreen** (`MainActivity`): the system bars are hidden, a swipe from the edge shows them for
  a moment, and they're hidden again whenever the game is back in front.
- **Backups:** the app writes the file to its cache and hands it to Android's share sheet
  (`@capacitor/filesystem`, `@capacitor/share`), since the WebView doesn't download files.
  Restoring goes through the system's file picker, as on the web. The Backup card says progress is
  kept in the app (until it's uninstalled), and leaves out the browser's storage promise.
- **Contact:** the About page shows the studio's address, falcondeergames@gmail.com (in the app
  as text to copy, on the web as an email link). GitHub isn't shown in the final version.
